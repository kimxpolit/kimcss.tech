TÀI LIỆU TÍCH HỢP REST API V2

Hệ thống cung cấp API cho phép các nhà phát triển và đại lý tự động kiểm tra số dư, duyệt danh sách sản phẩm và mua tài khoản tự động bằng mã lệnh.

GET 1. Kiểm tra thông tin tài khoản & số dư

Endpoint: /api/profile.php?api_key={YOUR_API_KEY}

Mẫu phản hồi JSON (200 OK):
{
  "status": "success",
  "msg": "Lấy dữ liệu thành công!",
  "data": {
    "username": "client_demo",
    "money": 500000
  }
}
GET 2. Lấy danh sách sản phẩm & tồn kho

Endpoint: /api/products.php?api_key={YOUR_API_KEY}

Mẫu phản hồi JSON (200 OK):
{
  "status": "success",
  "data": [
    {
      "category_name": "CLONE FACEBOOK",
      "products": [
        {
          "id": 1,
          "name": "Clone FB 2FA Nuôi Cổ",
          "price": 5000,
          "amount": 250,
          "description": "Bao login 1 đổi 1 trong 24h"
        }
      ]
    }
  ]
}
POST / GET 3. Mua sản phẩm tự động

Endpoint: /ajaxs/client/product.php

Tham số yêu cầu:

  • action: buyProduct
  • api_key: API Key của bạn
  • id: ID sản phẩm cần mua
  • amount: Số lượng cần mua
  • coupon: Mã giảm giá (nếu có)
Mẫu phản hồi thành công:
{
  "status": "success",
  "msg": "Tạo đơn hàng thành công!",
  "trans_id": "ORD9283719",
  "data": "1000827282|pass123|2FA_SECRET\n1000918273|pass456|2FA_SECRET"
}
