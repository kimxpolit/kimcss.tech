POST 4. Tạo đơn mua hàng tự động (Order Placement)

Hệ thống kiểm tra số dư ví, trừ tiền và xuất trực tiếp danh sách tài khoản theo cơ chế FIFO.

POST / GET
Tham số truyền vào (Payload):
Tham số Kiểu Bắt buộc Mô tả
api_key String Có Khóa API Key của tài khoản người mua
id Integer Có ID sản phẩm cần mua
amount Integer Có Số lượng cần mua (Tối thiểu 1)
coupon String Không Mã giảm giá khuyến mãi (nếu có) 
{
    "status": "success",
    "msg": "Tạo đơn hàng thành công!",
    "trans_id": "API_M3KZ4_9A21",
    "data": [
        "1000040304952|GUTJXYIFPWLHCNDOMBRKVAQESZ",
        "1000087676467|IVMRLABECWTQYUXHPOFNJDSZGK"
    ]
}
Mẫu Code Tích Hợp Đa Ngôn Ngữ
curl -X POST "/api/buy_product" \
  -H "Content-Type: application/json" \
  -d '{
    "api_key": "YOUR_API_KEY",
    "id": 1,
    "amount": 2
  }'
const response = await fetch('/api/buy_product', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        api_key: 'YOUR_API_KEY',
        id: 1,
        amount: 2
    })
});
const result = await response.json();
console.log(result);
import requests

url = "/api/buy_product"
payload = {
    "api_key": "YOUR_API_KEY",
    "id": 1,
    "amount": 2
}
response = requests.post(url, json=payload)
print(response.json())
